# Browser Testing Agent: учебный проект

Цель проекта — самостоятельно построить агентную систему, которая получает
тест-кейс, управляет браузером, записывает маршрут, объясняет ошибки и формирует
кандидатов в баги.

Используем:

- Python 3.11+;
- Pydantic для контрактов данных;
- LangChain для работы с LLM и structured output;
- LangGraph для состояния и оркестрации;
- Playwright для детерминированного управления браузером;
- Ollama с `qwen3.5:35b`.

## Принцип обучения

Код агента пишет ученик. Ментор:

1. объясняет архитектурный принцип;
2. дает небольшое задание;
3. проверяет реализацию и тесты;
4. показывает проблемы и альтернативы;
5. выдает следующий этап.

Мы не начинаем с готового большого агента. Каждый компонент сначала реализуется
изолированно, покрывается тестами и только затем включается в LangGraph.

## Текущий этап

Первые восемь уроков завершены. Откройте
[девятый урок](docs/lessons/09-browser-observer.md) и добавьте Observer, чтобы
агент самостоятельно получал snapshot браузера.

Проверка:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Сейчас тесты должны падать: это стартовая точка задания.

## План проекта

1. Доменные модели.
2. Состояние LangGraph.
3. Первый граф без LLM и браузера.
4. Browser session и observer.
5. Planner со structured output.
6. Цикл observe-plan-act.
7. Validator и защита от повторов.
8. Judge и recovery.
9. Анализ возможных багов.
10. Отчеты и генерация Playwright-тестов.
