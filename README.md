# UI Browser Agent

AI-powered browser automation agent built with LangChain, MCP and Playwright.

## Tech Stack

* Python 3.11+
* LangChain
* LangGraph
* Playwright MCP
* Ollama
* Qwen3


## Start MCP Server

```bash
npx @playwright/mcp
```

or run your local MCP server configuration.

## Run Agent

```bash
python agent.py
```
