# AI Website Testing Agent — Обзор системы

## Что это

Агентская система автоматического тестирования веб-сайтов. Она принимает тест-кейсы написанные на **русском естественном языке** (без кода и без жёстких локаторов) и самостоятельно:

1. Планирует последовательность действий в браузере
2. Управляет реальным браузером через Playwright
3. Фиксирует результат каждого шага (passed / failed / broken)
4. Находит баги на сайте и составляет отчёты о них
5. Генерирует готовый pytest-тест с Allure-разметкой
6. Публикует полный HTML-отчёт в Allure

## Ключевая идея

Тест-кейс — это **только человеческое описание**. Никаких XPath, CSS-селекторов, кода или шаблонов. Агент сам решает, как выполнить каждый шаг.

```yaml
# Вот как выглядит тест-кейс:
steps:
  - step: "Войти под 'standard_user' с паролем 'secret_sauce'"
    expected: "Пользователь попадает на страницу Products"

  - step: "Добавить «Sauce Labs Backpack» в корзину"
    expected: "Кнопка меняется на «Remove», счётчик корзины показывает «1»"
```

Агент сам определяет, что нужно ввести в поля Username и Password, как найти кнопку Login, как проверить редирект, и т.д.

## Технологический стек

| Компонент | Технология | Назначение |
|-----------|-----------|-----------|
| Агентская оркестрация | LangGraph (StateGraph) | Граф состояний с условной маршрутизацией |
| Браузерная автоматизация | Playwright (sync API) | Управление реальным Chrome |
| LLM — планирование / анализ | qwen3.5:35b (Ollama) | Планировщик и наблюдатель |
| LLM — генерация кода | qwen2.5-coder:14b (Ollama) | Генератор pytest-тестов |
| Отчётность | Allure | HTML-отчёт со скриншотами |
| Трассировка | LangSmith | Трейсы LLM-вызовов |
| Формат тест-кейсов | YAML | Человекочитаемые тест-кейсы |

## Демо-сайты

Система протестирована на трёх сайтах:

- **https://www.saucedemo.com/** — тренировочный интернет-магазин. 9 тест-кейсов, включая намеренно сломанного `problem_user`.
- **https://the-internet.herokuapp.com/** — площадка для тестирования UI-паттернов. 2 тест-кейса.
- **https://automationexercise.com/** — полноценный e-commerce. 11 тест-кейсов, включая сквозной сценарий покупки с оплатой картой.

## Быстрый старт

```bash
# Запустить один тест-кейс
python run_tests.py test_cases/saucedemo/tc_01_login_valid.yaml

# Запустить демо (5 кейсов, ~15 мин)
python demo.py --quick

# Открыть Allure-отчёт
& "C:\Program Files\allure-2.42.1\bin\allure.bat" serve allure-results
```
